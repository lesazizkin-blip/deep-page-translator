# Автотесты

Без зависимостей: нужны Node 22+ и Python 3.

```bash
npm test
```

Запускает `node --test "tests/*.test.mjs"` (константы и горячие клавиши, кеш, очередь, провайдер Google,
фоновый скрипт с имитацией `chrome.*` — в том числе без `commands`/`contextMenus`, как в Firefox для Android)
и `python -m unittest` (манифест и пакет `.xpi` для Firefox). Код content scripts требует DOM и проверяется
вручную по списку ниже.

# Ручные проверки

Перед проверками: загрузите расширение (см. README), откройте `chrome://extensions` →
карточка расширения: нет кнопки «Ошибки», нет предупреждений. Откройте DevTools
service worker'а (ссылка «service worker» в карточке): в консоли нет ошибок.

## 0. Базовое

- [ ] Popup открывается: язык «Русский», провайдер «Google», внизу нет ошибки проверки.
- [ ] Popup на `chrome://extensions` сообщает, что на служебной странице работать нельзя.
- [ ] Настройки → «Проверить провайдера» для Google: «Работает: …».
- [ ] DeepL без ключа → понятная ошибка «не указан API-ключ»; с неверным ключом → «неверный API-ключ (403)».
- [ ] LibreTranslate без URL → «не указан URL сервера»; с несуществующим адресом → «нет соединения».

## 2. Shadow DOM

Подойдут:
- https://shoelace.style/components/alert (документация на веб-компонентах), или
- любая страница, где в DevTools → Elements видны `#shadow-root (open)` с текстом (например,
  `chrome://`-страницы не подходят; YouTube использует Polymer/shadow DOM частично).
- Быстрый синтетический тест: на любой обычной странице выполнить в консоли
  ```js
  const h = document.body.appendChild(document.createElement('div'));
  h.attachShadow({ mode: 'open' }).innerHTML = '<p>Text inside the <b>shadow</b> root.</p>';
  ```

- [ ] Текст внутри shadow root переводится (после включения или в течение ~1 с, если элемент добавлен позже).
- [ ] Вложенные shadow roots (shadow внутри shadow) тоже переводятся.
- [ ] Стили и поведение компонентов не изменились (кнопки, раскрывающиеся блоки работают).
- [ ] «Показать оригинал» возвращает исходный текст внутри shadow DOM.

## 3. SPA и динамическая подгрузка

Подойдут: https://github.com (переходы между вкладками репозитория без перезагрузки),
https://news.ycombinator.com/ с раскрытием комментариев, любая лента с бесконечной прокруткой,
блоки `<details>` и аккордеоны.

- [ ] Включить перевод, перейти по внутренней ссылке SPA: новый контент переводится без нажатия кнопки.
- [ ] Прокрутить ленту с подгрузкой: новые элементы переводятся в течение ~1 с после появления.
- [ ] Раскрыть свернутый блок (`<details>`, аккордеон): текст внутри переведён.
- [ ] Поле ввода / редактор комментария (`textarea`, `contenteditable`) не трогается; набранный текст не переводится.
- [ ] Перевод не «мигает» и не переводится повторно (в Network service worker'а нет повторных запросов
      для одних и тех же блоков).

## 6. Прочее

- [ ] Настройки → «Горячие клавиши»: нажать на поле, затем `Ctrl+Shift+Y` — сохраняется сразу.
      На странице `Ctrl+Shift+Y` включает и выключает перевод, в том числе с фокусом внутри iframe Kaggle
      и в русской раскладке. Сочетание без Ctrl/Alt/Meta (например, просто `Y`) отклоняется с подсказкой.
      В popup внизу видны оба сочетания.

- [ ] Выделить текст → ПКМ → «Перевести выделенное»: появляется окно с оригиналом и переводом;
      закрывается по Esc или клику вне окна. В iframe Kaggle тоже работает.
- [ ] Сменить язык в popup на English при включённом переводе: страница переводится заново на английский.
- [ ] Провайдер «Встроенный в Chrome» (Chrome 138+): при первом переводе индикатор предлагает
      «Загрузить модель»; после клика идёт загрузка с процентами, затем перевод.
      В браузере без Translator API — понятное сообщение «Translator API недоступен…».
- [ ] Настройки → «Очистить кеш»: счётчик записей обнуляется.
- [ ] Отключить «Показывать оригинал при наведении»: подсказка больше не появляется.
- [ ] Добавить хост iframe (например, `kaggleusercontent.com`) в исключения: при переводе Kaggle урок
      в iframe остаётся на английском.
